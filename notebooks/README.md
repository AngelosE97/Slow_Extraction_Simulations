# Selected simulation examples

- **Initial_delta.ipynb**  
  Phase space visualization for beams with non-zero initial momentum deviation.

- **Steinbach.ipynb**  
  Stability region analysis across tune values using iterative simulation.

- **Betatron_Core.ipynb**  
  Simulation of beam extraction using a custom Betatron Core exciter.

- **RFKO_sawtooth_with_ripples.ipynb**  
  RFKO-based extraction using frequency modulation (sawtooth signal) and quadrupole ripple effects.
